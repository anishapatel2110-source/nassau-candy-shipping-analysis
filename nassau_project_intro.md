Nassau Candy Shipping Route Efficiency Analysis

Project Overview

This project analyzes factory-to-customer shipping routes for Nassau Candy Distributor to understand shipping time, delays, and delivery efficiency.

Objectives

- Analyze shipping lead times.
- Identify shipping delays and patterns.
- Compare shipping modes and factory performance.
- Recommend ways to improve shipping efficiency.

Tools Used

- Python
- Data Analysis
- Streamlit
- GitHub

Project Deliverables

- Research Paper
- Executive Summary
- Interactive Dashboard
